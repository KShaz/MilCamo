# Evaluation Protocol

The evaluation metrics used in this work follow the standard evaluation protocol adopted in the camouflaged object detection literature. Specifically, the following metrics are employed:

* Structural Similarity Measure (Sα)
* Adaptive E-measure (Eϕᵃᵈ)
* Weighted F-measure (Fβω)
* Mean Absolute Error (MAE)

The evaluation script (`evaluate.py`) reproduces the exact evaluation procedure used in the manuscript. The implementation follows the standard COD evaluation framework widely adopted by previous studies.
